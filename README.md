## Run locally

1. คัดลอกโฟลเดอร์ไปไว้ที่ `xampp/htdocs/web_portfolio`
2. เปิด Apache ใน XAMPP
3. เข้า http://localhost/web_portfolio/

เว็บที่ออนไลน์บน GitHub Pages เป็นไฟล์ HTML ที่ build จากหน้า PHP ชุดนี้ (branch `gh-pages`)
